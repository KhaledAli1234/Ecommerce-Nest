# E-Commerce Backend (NestJS)

Backend API for an E-Commerce platform with product management, categories, shopping cart, order processing, and user authentication. Built using NestJS, MongoDB, GraphQL, and Socket.io for real-time updates.

## Features
- Product and category management
- Shopping cart and order processing
- JWT authentication and role-based access
- REST and GraphQL APIs
- Real-time notifications with Socket.io

## Tech Stack
- Node.js
- NestJS
- GraphQL
- Socket.io
- MongoDB
- JWT
- REST API

## Installation
1. Clone the repo
2. Run `npm install`
3. Run `npm run start:dev`
